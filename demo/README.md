# ResumeStack Demo

A demo for the ResumeStack library, a TypeScript component for resuming Paystack transactions with modal interface and theme support. Not affiliated with Paystack.

## Usage

1. Set up environment: Create `.env` with `PAYSTACK_SECRET_KEY=your_secret_key` in the `demo` folder.
2. Use the `demo` script: `npm run demo` from the project root.

Initialize a transaction by clicking the button, then resume it using the modal.
